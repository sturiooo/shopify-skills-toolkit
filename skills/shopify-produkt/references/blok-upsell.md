# Redesign bloku upsell: slider → statyczna lista poziomych wierszy (Sleek/FoxEcom)

**Wdrożone:** sklep z suplementami dla psów (2026-06, blok `complementary` w `snippets/product-information-blocks.liquid` + schema w `sections/main-product.liquid`). Przeróbka wg inspiracji: pionowy stos wierszy `[miniatura] [nazwa+opis+cena] [pigułka „Dodaj do koszyka"]`.

- **Przepisując duży blok, podmieniaj TYLKO CSS strukturalny, a warunkowe reguły kolorów/rozmiarów zostaw nietknięte, REUŻYWAJĄC tych samych nazw klas** (`.cmp-card__media`, `.cmp-card__btn`, `.product-card__title`, `.complementary-products .f-price`). Dzięki temu blok `{% if c_color %}…{% endif %}` (kilkadziesiąt linii) działa dalej bez zmian, a edycja jest mała i bezpieczna. Stare, nieużywane klasy w warunkach (`.cmp-nav__btn`) są nieszkodliwe.
- **AJAX dodawania do koszyka zostaje bez zmian** (handler `submit` na `.cmp-card__btn-form`, patrz gotcha „cartType=page łamie product-form" w `produkty-komplementarne.md`). Zmieniasz tylko wygląd przycisku (pigułka + inline SVG koszyka), nie mechanikę.
- **Opis pod nazwą z metafielda** konfigurowalnego: setting `text` „namespace.key" → `split: '.'` → `product.metafields[ns][key].value` (**bracket access ze zmiennymi działa**). Zostaw default (`custom.upsell_opis`), guard `if ns and key`. Wymaga metafielda **tekstowego** (dla rich text `.value` zwróciłby JSON, wtedy `| metafield_tag`).
- **Line-clamp na rich text celuj w `<p>`, nie w kontener**: `.rte` wypisuje `<p>`, a `-webkit-line-clamp` na kontenerze z dzieckiem-blokiem `<p>` działa zawodnie. `font-size` opisu też na `<p>` z `!important` (ta sama gotcha co przy sliderze opinii). Liczba linii = setting `range` (0 = bez limitu).
- **Miniatury bez „kwadratu":** tło `.cmp-card__media` na `transparent` + minimalny `padding`; rozmiar boksu jako osobne settingi px desktop/mobile (nie tylko `--cmp-img %` skalujące zdjęcie w boksie: to dwa różne pokrętła). `for product in cmp_products` wewnątrz `capture` bezpiecznie shadowuje globalne `product` (po capture wraca produkt strony).
