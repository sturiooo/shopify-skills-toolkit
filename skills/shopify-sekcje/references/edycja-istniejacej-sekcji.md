# Dostosowywanie ISTNIEJĄCEJ sekcji motywu bez psucia reszty sklepu (`recently-viewed-products`, Sleek/FoxEcom)

**Wdrożone:** sklep z suplementami dla psów (2026-06, motyw Sleek, FoxEcom). Lekcja z dostosowania natywnej sekcji „Ostatnio oglądane" (Sleek/FoxEcom): dodanie nadtytułu/podtytułu, krótkich opisów pod produktami i nazw lowercase, bez ruszania współdzielonych snippetów.

- **Recently-viewed renderuje się DWA RAZY:** raz pusto (`.hidden`) na załadowaniu strony, potem **przez AJAX**: `recently-viewed-products.js` fetchuje `routes.search_url?section_id={id}&type=product&q=...` i ta sama sekcja renderuje się z wypełnionym `search.results` / `search.terms`. **Wniosek:** customowy Liquid w pętli `for product in search.results` (np. dodatkowy opis) DZIAŁA, bo AJAX re-renderuje sekcję z dostępnymi produktami. Nie trzeba własnego JS do danych.
- **Nadtytuł/podtytuł w sekcjach FoxEcom JUŻ ISTNIEJĄ:** `snippets/section-heading.liquid` renderuje `subheading` = **eyebrow/nadtytuł** (nad H2, klasa `.section__subheading`), `heading` = H2, `description` = **podtytuł** (pod H2, rte). Nie wymyślaj własnego nagłówka: wypełnij/ustaw default tym polom. Sprawdź czy schema ma `subheading` + `description` (często są).
- **Customizacja sekcji używającej WSPÓŁDZIELONEGO snippetu** (`card-product` jest globalny: edycja zmieniłaby wszystkie karty w sklepie): **nie edytuj snippetu**. Zamiast tego **dorzuć własny markup PO `{% render 'card-product' %}`** wewnątrz elementu slajdu (`<p class="rvp-card-desc">…`) i **scope'uj stylowanie przez `.section-{{ section.id }}`**. Lowercase tytułów też scoped: `.section-{{id}} .product-card__title { text-transform: lowercase } ::first-letter { uppercase }` (klasa tytułu w `card-product` = `.product-card__title`). Efekt tylko w tej sekcji, reszta kart nietknięta.
- **Krótki opis z metapola LUB opisu produktu:** setting `text` „namespace.key" → `split: '.'` → `product.metafields[ns][key].value`, fallback `product.description`, finalnie `| strip_html | truncatewords: N`; obcięcie wizualne do N linii przez `-webkit-line-clamp` (display:-webkit-box + box-orient:vertical + overflow:hidden).
- **„Sprawdź czy nic nie hardkodowane":** w dobrze zbudowanej sekcji motywu user-facing teksty idą przez `t:` (schema) i `| t` (markup), szukaj stringów PO ANGIELSKU jako `"default"` (tu jedyny: heading „Recently viewed products" → zmień na PL). Snippety/klasy/`data-*` to nie hardkod treści.
- **Zachowaj mechanikę przy dostosowaniu:** klasy slidera (`.swiper`/`.swiper-wrapper`/`.swiper-slide`, `swiper-controls`, `product-slider`), custom element `<recently-viewed-products data-url>`, ładowane `*.js` i `card-product` muszą zostać, dokładasz tylko nad/obok.
